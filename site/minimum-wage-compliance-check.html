Minimum wage compliance check

Is this hourly rate legal at this address? Ask in the paycheck call.

The minimum wage that binds an employer is the highest of the federal, state and any local figure that applies. Local ordinances now cover 69 jurisdictions in the data the engine carries, so a state figure alone is often wrong. Add a minimumWageCheck to the paycheck request and the answer comes back with the calculation.

What you send

"workState": { "code": "WA" },
"minimumWageCheck": { "hourlyRate": 1800, "locality": "seattle", "employeeCount": 250 }
FieldMeaning
hourlyRateThe employee's hourly rate in cents: $15.00 is 1500.
localityA local ordinance id or name, such as seattle.
employeeCountEmployer headcount, where the ordinance has size tiers.
tippedCompare with the tipped cash floor.
regionA named sub-region such as New York "downstate" or Oregon "portland_metro".

One billed call

The check is answered in the same call as the paycheck and billed as one calculation. Federal, state and local figures are all considered, and the binding one is reported.

What it is for

  • Catching a rate that fell below the floor after a state or city increase on January 1 or July 1.
  • Checking an offer before it is sent.
  • Showing a compliance flag next to the rate in a scheduling or HR tool.

Limits

It compares a rate with a floor. It does not decide whether an employee is exempt, whether a particular tip credit is allowed for a job, or whether a sector-specific minimum applies beyond those the data covers. See minimum wage by state for the state figures and coverage for the local ones.

Questions

Can the payroll API check minimum wage?

Yes. Add minimumWageCheck with an hourly rate to the paycheck request and it compares the rate with the binding federal, state and local minimum wage in the same call.

Is the minimum wage check billed separately?

No. It is answered in the same call and billed as one paycheck calculation.

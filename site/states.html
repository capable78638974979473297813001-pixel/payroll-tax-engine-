B08 · COMPONENT STATES

States

Every interactive component in each of its states, drawn with the same tokens as the product pages. This board is internal. It has no product route in the onboarding click path.

01 · Text input

Focus is a 2px cobalt border on all sides and a cobalt caret (caret-color). The caret is the browser’s, so it is not a drawn 2×32 bar. “Enter a valid work email.” is the message the signup form shows before it calls the server. If the server rejects the address it returns its own error string on the field.

02 · Buttons

Hover: primary turns black; secondary fills panel; text underline thickens to 4px. Pressed: primary black with a 2px cobalt inset; secondary inverts to black; text fills panel. Focus: 2px cobalt outline, 2px offset, the same ring as :focus-visible (the frame left button focus open). Loading: the label stays, a 12px spinner replaces the arrow, and the button is disabled so it cannot be clicked — the fill stays cobalt, not the hairline disabled fill. Disabled: hairline fill and placeholder text. Secondary disabled keeps a hairline border. Text disabled uses a placeholder label and underline.

03 · Verify code

The frame’s “That code didn’t match. 2 tries left.” is not returned by the API. A wrong, expired, or unknown code all respond with “That code is incorrect or has expired. Request a new one if needed.” After 8 wrong attempts the code is burned, and the hourly cap uses the same sentence: “Too many wrong codes. Request a new one.”

05 · Alert / toast

Key copied to clipboard.
Could not send the code. Try again in a minute.

Inline: full width of its container, 24px above the element it refers to. Toast: the same component, fixed 24px from the bottom-right, dismissed after 4 seconds. Success uses role="status"; errors use role="alert". “Key copied to clipboard.” is the copy after a successful clipboard write. “Could not send the code. Try again in a minute.” is the client fallback when resend fails and the server sends no error string. A server error replaces it. The frame’s “We couldn’t send the code…” is not used.

States

Every interactive component in each of its states, drawn with the same tokens as the product pages. This board is internal. It has no product route in the onboarding click path.

01 · Text input

02 · Buttons

Hover: primary turns black; secondary fills panel; text underline thickens to 4px. Pressed: primary black with a 2px cobalt inset; secondary inverts to black. Loading: label stays, a spinner replaces the arrow, the button is not clickable.

03 · Verify code

The frame’s “2 tries left” is not returned by the API. A wrong code responds with “That code is incorrect.” After 8 wrong attempts the code is burned: “Too many wrong codes. Request a new one.”

04 · Password rule · stepper · card

05 · Alert / toast

Key copied to clipboard.
We couldn’t send the code. Try again in a minute.

Inline: full width of its container, 24px above the element it refers to. Toast: the same component, fixed 24px from the bottom-right. “Key copied to clipboard.” is the copy used after a successful clipboard write. The resend failure toast uses the server’s error string when one is returned.

Item shape is { path, message }, from site/lib/validate.ts. The frame’s field key is not what the API sends. Headers on a 422 that got past the limiter include X-Request-Id, Omnia-Mode, and RateLimit-*. 401 responses have X-Request-Id and no Omnia-Mode.

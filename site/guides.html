  • Net-to-gross (gross-up) API When the promise is a take-home amount, the gross has to be found. The engine only goes forward, so ours searches it.
  • Compare two paychecks API A raise, a move, a new deduction: the compare endpoint attributes the change in net pay to each input that changed.
  • State income tax withholding API Fifty-one jurisdictions, three kinds of method, and one request shape.

  • Bonus tax withholding Bonuses and commissions are supplemental wages. They can be withheld differently from regular pay.

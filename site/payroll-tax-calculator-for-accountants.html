Who it is for

Payroll tax calculator for accountants

Check a client's payroll without rebuilding their rules in a spreadsheet.

Accountants meet payroll mostly as a question: is this withholding right, what will this hire cost, why did this quarter's liability move. A calculator that shows each line with the method behind it answers those quickly. The Omnia.tax calculator runs the same engine as the API, so a number you check by hand is the number your client's software would get.

What accountants use it for

  • Spot-checking a client's payroll provider. Rerun a paycheck with the same inputs and compare line by line. See the audit method.
  • Planning. What does a raise, a bonus or a move cost the employee and the employer? The compare function explains the difference step by step.
  • Onboarding a client. Their first payroll in a new state: which lines should appear, which certificate is needed.
  • Quarter-end questions. Why a state unemployment liability is high in the first quarter: the wage base resets each January.

A worked check

A client's employee in Columbus, Ohio is paid $3,000.00 biweekly. The engine returns federal income tax of $320.38, Ohio income tax of $75.77, Columbus city tax of $75.00, Social Security of $186.00 and Medicare of $43.50, for net pay of $2,299.35. Each line has a sentence you can quote in a workpaper.

What it does not replace

  • Professional judgement about worker classification, taxability of a particular payment or exempt status.
  • Filing and deposits, which the engine does not do.
  • The agency's own publications, which remain the authority. Each state page links the withholding guide it was read from.

Free to try

A test key costs nothing; the calculator is open once you sign in. No developer is needed to use the calculator.

Questions

Can an accountant use the calculator without coding?

Yes. The browser calculator takes an address or state, pay, a Form W-4 and deductions and shows every tax line with an explanation. No API key or code is needed once you are signed in.

Is it a substitute for the payroll provider?

No. It calculates withholding and employer taxes to check or plan. It does not run payroll, file returns or deposit tax.

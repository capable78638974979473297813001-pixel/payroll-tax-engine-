Payroll tax calculation API

POST a paycheck. Get every tax line, who pays it, and net pay.

A payroll tax calculation API takes the facts of one paycheck and returns the taxes on it. With Omnia.tax that is a single POST /v1/paycheck: earnings, deductions, the employee's Form W-4, year-to-date wages and a work location go in; a list of tax lines and net pay come out, as JSON, with every amount in integer cents. It calculates. It does not file returns, deposit tax or pay anyone.

What one call does

The request below is a single employee in Texas paid $3,000.00 biweekly. Texas has no state income tax, so the response carries federal income tax, Social Security and Medicare for the employee, and Social Security, Medicare, federal unemployment tax and Texas unemployment tax for the employer.

{
  "checkDate": "2026-09-15",
  "payFrequency": "biweekly",
  "earnings": [{ "code": "REG", "category": "regular", "amount": 300000 }],
  "deductions": [],
  "federalW4": { "filingStatus": "single", "multipleJobs": false,
    "dependentCredit": 0, "otherIncome": 0, "deductions": 0, "extraWithholding": 0 },
  "ytd": { "socialSecurity": 0, "medicare": 0, "futa": 0 },
  "workState": { "code": "TX" }
}

The response is shaped like this (abridged; the real one lists every line):

{
  "result": {
    "checkDate": "2026-09-15",
    "grossPay": 300000,
    "taxes": [
      { "id": "US_FIT", "name": "Federal Income Tax", "payer": "employee",
        "taxableWages": 300000, "amount": 32038, "detail": "…" },
      { "id": "US_SS_EE", "name": "Social Security", "payer": "employee",
        "taxableWages": 300000, "amount": 18600, "detail": "…" }
    ],
    "employeeTaxTotal": 54988,
    "employerTaxTotal": 32850,
    "netPay": 245012
  }
}

Why the rules live behind an API

  • The rules change: wage bases move every January, and states revise rates and formulas during the year. You call the same endpoint; the check date picks the right year.
  • Local tax is the long tail. The engine carries 4,141 local jurisdictions in 15 states and finds them from an address with POST /v1/address.
  • Each line says how it was reached, so a payroll specialist can audit a figure without reading code.
  • Money is integer cents on the way in and out. There is no floating-point dollar anywhere to round the wrong way.

Questions

What does a payroll tax calculation API do?

It takes the earnings, deductions, withholding certificates, year-to-date wages and work location of one paycheck and returns each payroll tax with the wages it applied to, who pays it, and net pay.

Does the API file or pay the tax?

No. Omnia.tax calculates withholding and employer taxes. You, or your payroll provider, still file returns and deposit the tax.

What format are the requests and responses?

JSON over HTTPS, with every money amount in integer cents. A request that sends a decimal dollar amount is rejected with a field-level error.

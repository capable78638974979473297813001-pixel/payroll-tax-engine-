Net-to-gross calculator API

When the promise is a take-home amount, the gross has to be found. The engine only goes forward, so ours searches it.

Net-to-gross, or gross-up, answers: what gross pay leaves the employee a given take-home amount? It comes up in sign-on bonuses promised after tax, relocation payments, and offers quoted as net.

Why it is not a formula

Withholding has brackets, caps and per-tax wage bases, so net pay is not a straight multiple of gross. POST /v1/paycheck/gross-up runs the real engine on candidate amounts, in whole cents, and returns the smallest amount whose net pay reaches the target. The answer and the returned paycheck are engine results, not an estimate.

Two worked examples

Target take-home of $2,500.00 on a biweekly paycheck:

LocationGross neededNet payExact
Texas (no state income tax)$3,070.92$2,500.00Yes
Columbus, Ohio (state and city tax)$3,309.36$2,500.00Yes

The Ohio employee needs $238.44 more gross for the same take-home, because of state and city tax.

When the target is skipped

Occasionally a tax step or rounding rule makes a one-cent change in gross move net by two cents, so an exact target does not exist. The response then returns the smallest amount that reaches it with exact: false and how many cents it is over.

The request

POST /v1/paycheck/gross-up
{ ...a paycheck request..., "grossUp": { "targetNetPay": 250000, "earningIndex": 0 } }

The earning at earningIndex is the one solved for; its amount is ignored. The response includes request with the solved amount filled in, so you can reuse it, and result, the full paycheck. Billed as one paycheck.

Questions

How do you calculate gross pay from net pay?

There is no single formula, because withholding uses brackets and caps. The usual method is to search: try a gross, calculate the net, and adjust until the net matches. Omnia.tax does this with the real engine, in whole cents.

What is a payroll gross-up?

Paying an employee enough gross that the amount they take home after tax equals an agreed figure, common for after-tax bonuses and relocation payments.

Is the gross-up answer exact?

Usually to the cent. If a tax step skips the target, the response returns the smallest gross that reaches it, marks exact as false and shows how many cents over it is.

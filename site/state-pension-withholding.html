State income tax withholding on pensions and annuities

States do not agree. Some withhold unless the payee opts out, some only when asked, some not at all. Here is what we have checked, and what we have not.

Only the state the payee lives in withholds: federal law (4 U.S.C. 114) bars a state from taxing a nonresident's retirement income. In the API, send that state as residenceState (or workState if it is all you send), and anything the payee told the payer in pension.stateElection.

The states we calculate

28 states and the District, each read from that state's own revenue agency and dated. Where a state publishes a rule for one kind of payment and not another, the other kind is marked not calculated.

The states we do not calculate

These have either not been checked against the state's own guidance, or the guidance we read does not give a rule for the payment. They return no state line and a warning, never a zero that looks like a result:

  • Delaware. Delaware's pension office offers its own form; the Division of Revenue's payer rule was not confirmed.
  • Kansas. Kansas follows federal withholding (required when federal is required, voluntary when federal is), but the guide does not state a method for pension payments.
  • Oregon. Oregon pension payers commonly default to 8% on lump sums, but Oregon's own payer rule was not found.
  • Pennsylvania. Pennsylvania's guidance read for this build does not address payer withholding on retirement distributions.

Every other state that taxes wages is also not calculated for pensions. A state with no income tax on wages needs none.

What no state result covers

  • Local withholding on pension payments.
  • Direct rollovers and trustee-to-trustee transfers, which states exempt; send them as no payment.
  • Nonresident payees with a state address who file an opt-out: the engine goes by the state you send.

Questions

Do states withhold income tax on pensions?

It depends on the state. Some require it unless the payee opts out (for example Connecticut, Minnesota, Michigan, North Carolina and Iowa), some only withhold when the payee asks (for example Alabama, Arizona, Illinois, New York and New Jersey), and Mississippi does not tax retirement income at all.

Which state withholds on a pension, the payer's or the payee's?

The payee's. Federal law bars a state from taxing the retirement income of someone who lives elsewhere, so the state is the one the payee lives in.

What if the payee gave the payer no state form?

Each state sets its own default. Connecticut withholds 6.99%, Minnesota 6.25%, Michigan 4.25%, North Carolina treats a periodic payee as single with no allowances and withholds 4% of a lump sum, and states that only withhold on request withhold nothing.

Why is my state missing?

We list a state only when we have read a rule in its revenue agency's own guidance. Where the guidance was missing or unclear, the engine returns a warning instead of guessing.

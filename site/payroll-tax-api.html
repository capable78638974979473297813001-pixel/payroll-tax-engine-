Payroll tax API

Federal, state, local and employer payroll tax for one paycheck, from one HTTP call.

Omnia.tax is a payroll tax calculation API. You send a paycheck and get back every tax line: who pays it, the wages it applied to, the amount in cents, and a short explanation of the math.

One request, every tax

curl https://api.omnia.tax/v1/paycheck \
  -H "Authorization: Bearer $KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "checkDate": "2026-09-15",
  "payFrequency": "biweekly",
  "earnings": [{ "code": "REG", "category": "regular", "amount": 300000 }],
  "deductions": [],
  "federalW4": { "filingStatus": "single", "multipleJobs": false,
    "dependentCredit": 0, "otherIncome": 0, "deductions": 0, "extraWithholding": 0 },
  "ytd": { "socialSecurity": 0, "medicare": 0, "futa": 0 },
  "workState": { "code": "OH", "certificate": { "residenceCity": "Columbus", "workCity": "Columbus" } }
}'

What you get back

  • Federal income tax from the employee's Form W-4, Social Security, Medicare and Additional Medicare.
  • State income tax for all 50 states and DC, with each state's own formula and withholding certificate.
  • Local taxes where the data has them: 4,141 jurisdictions across 15 states, including Ohio and Pennsylvania municipalities and school districts.
  • Employer taxes: FUTA, state unemployment, and state paid-leave contributions.
  • Garnishment limits and a minimum-wage check on the same call, billed as one call.

Built for developers

  • Plain JSON. Integer cents everywhere, a published JSON Schema and OpenAPI 3.1 document, and field-level validation errors.
  • Effective-dated rules. The check date picks the tax year, so a correction run for an earlier year uses that year's rules.
  • Explainable lines. Each tax line carries a detail string. When a rate rests on a weaker source than the levying body's own form, the response says so in notices.
  • Address resolution. POST /v1/address turns a work and home address into the state, the local jurisdictions and the certificate a paycheck needs.

Questions

What is a payroll tax API?

An HTTP service that takes one paycheck (earnings, deductions, the employee's W-4 and work location) and returns the payroll taxes: federal, state and local withholding, Social Security, Medicare and the employer taxes.

How much does the Omnia.tax payroll tax API cost?

$0.08 per paycheck calculation after a 14-day free trial. There are no seat fees.

Does Omnia.tax file or pay payroll taxes?

No. It calculates the tax. It does not file returns, deposit or remit tax, pay employees or move money, and it does not give tax advice.

Which states and years does it cover?

All 50 states and DC for 2025, 2026 and 2027 (2027 is provisional where a state has not yet published its tables), plus local taxes in 15 states covering 4,141 jurisdictions and 69 local minimum wage ordinances.

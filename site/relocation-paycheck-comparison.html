Relocation paycheck comparison

What does a move do to take-home pay? Ask for the difference, not two numbers.

When an employee is offered a role in another state, the question is not what each paycheck is. It is what changes and why. The compare endpoint runs both paychecks through the engine and walks from one to the other one input change at a time, so every step is an engine result.

Texas to California

The same $3,000.00 biweekly check. Net pay moves from $2,450.12 in Texas to $2,277.06 in California, a drop of $173.06.

The request

POST /v1/paycheck/compare
{ "before": { …the Texas paycheck… },
  "change": { "workState": { "code": "CA", "certificate": {} } } }

Send after as a full second paycheck, or change with only the fields that differ. The response has totals, taxes (only those that moved), inputChanges and steps.

Billing

A successful comparison is billed as two paycheck calculations and nothing when refused. See the compare endpoint.

Limits

A paycheck comparison does not account for the cost of living, income taxes beyond withholding, property or sales taxes, or the employee's total return. It compares withholding on one check.

Questions

How do I compare take-home pay between two states?

Use the compare endpoint with the same paycheck and a changed work state. It returns both results and a step-by-step explanation of the difference.

Does the comparison include cost of living?

No. It compares tax withholding on one paycheck, not living costs or other taxes.

Address to tax jurisdiction lookup API

Resolve an employee once, from their addresses, and reuse the result on every pay run.

Payroll tax depends on where people work and live, but payroll systems store addresses as text. POST /v1/address turns a one-line work address, and optionally a home address, into the facts a paycheck needs.

What you send

POST /v1/address
{ "workAddress": "77 E Gay St, Columbus, OH 43215",
  "residenceAddress": "233 Broadway, Yonkers, NY 10701",
  "checkDate": "2026-09-15" }

What comes back

FieldMeaning
state, residenceStateThe work state, and the home state when it differs.
certificateThe state and local facts to put in workState.certificate: city, county, school district and the state's own codes.
work, residenceFor each address: whether it matched, the matched address, precision and point source, coordinates.
notResolvableTaxes that could not be checked, for example residence-based taxes when no home address was given.
warnings, fullyResolvedLow-confidence reasons, and whether everything needed was found.

Honest about gaps

If only a work address is sent, the response lists the residence-based taxes it could not check, so a missing home address does not silently become a missing tax. A lookup is recorded and not billed; only the paycheck calculation is.

The calculator uses this endpoint to fill in the state and local fields from an address.

Questions

Why does payroll need a home address?

Several taxes depend on where the employee lives: city and school-district taxes, resident-state tax, and reciprocity between states. Without it those taxes cannot be determined.

Is an address lookup billed?

No. Address lookups are recorded but not billed. The paycheck calculation is the billed call.

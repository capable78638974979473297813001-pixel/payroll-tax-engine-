SUTA wage base ranked by state

Where the first dollars of each employee's pay cost the most.

State unemployment tax applies to the first slice of each employee's yearly wages, the wage base. States set it independently: from $7,000 in Tennessee to $78,200 in Washington. Combined with the new-employer rate it gives the most an employer pays per employee.

Reading the table

  • Experienced employers pay an assigned rate, not the new-employer rate, so the real cost can be lower or higher.
  • The wage base resets each January, so unemployment tax is front-loaded in the year.
  • Some states index the base to wages each year, so it rises without legislation.
  • The federal FUTA base is separate and small: see FUTA and SUTA calculation.

2026 retirement deferral limits in payroll

What stays pre-tax, and when it stops.

Retirement plans cap how much an employee can defer from pay in a year. When a payroll system keeps treating deferrals as pre-tax after the cap is reached, it under-withholds. The engine reads the cap from its federal rule file for the check date's year, and reports what stayed pre-tax so you can carry it forward.

The limits in the 2026 rule file

Plan type2026 limit
401(k) and 403(b) combined (IRC 402(g))$24,500
Governmental 457(b)$24,500
SIMPLE plan$17,000

The 401(k) and 403(b) figure is one shared limit: an employee contributing to both gets $24,500 between them, not each.

How it works in a request

"deductions": [{ "code": "401K", "category": "deferral_401k", "amount": 300000 }],
"ytd": { "socialSecurity": 0, "medicare": 0, "futa": 0,
         "electiveDeferrals": { "section402gAggregate": 2400000 } }

With the year's deferrals sent in, a check that would exceed the limit has only the remaining part treated as pre-tax. The response's electiveDeferrals block shows the totals to carry into the next request.

What to supply yourself

  • Catch-up eligibility. Age-based catch-up contributions raise the limit for some employees, which is an employee fact the engine cannot know.
  • Contributions to another employer's plan in the same year, which also count toward the 402(g) limit.
  • Roth and after-tax contributions, which are post-tax deductions and do not count as pre-tax deferrals.

Where to read the primary source

The 2026 limits are from the IRS announcement of cost-of-living adjustments. Confirm any figure against the IRS before relying on it for plan administration.

Questions

What is the 401(k) deferral limit for 2026?

The elective deferral limit under section 402(g) is $24,500 for 401(k), 403(b) and governmental 457(b) plans, with the 401(k) and 403(b) limit shared. The SIMPLE plan limit is $17,000.

What happens when the limit is reached mid-year?

The engine treats only the remaining part of a deferral as pre-tax and returns electiveDeferrals so you can carry the total forward.

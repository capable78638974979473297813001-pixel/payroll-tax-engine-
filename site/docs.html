Calculate US payroll taxes with one JSON call. 14-day free trial, then $0.08 per paycheck calculation, pay as you go.

QuickstartcURL
curl https://api.omnia.tax/v1/paycheck \
  -H "Authorization: Bearer $OMNIA_API_KEY" \
  -H "Content-Type: application/json" \
  -d @paycheck.json

// 200 OK, amounts in cents
{ "result": { "grossPay": 140000, "netPay": 112965, … } }

paycheck.json is the request body shown under POST /v1/paycheck. The console runs the same case, and seven others, from its examples menu.

Making requests

POST JSON to /v1/paycheck with Authorization: Bearer and Content-Type: application/json. A successful body is { "result": { … } }. Amounts are integer cents.

Authentication

Keys are shown once, stored as a hash, and sent as a bearer token. Issued keys start with sk_live_ and return real calculations. An older key that is no longer accepted returns 401 key_not_accepted. Sign in and issue a new key. Every response from an accepted key includes Omnia-Mode: live.

No key in this session

The full key is shown once, on the key screen.

Money and rounding

Every money field on the request and the response is an integer number of cents. Do not send dollars. A line whose detail says it is not modelled returns amount 0, which is not the same as a calculated zero.

Rate limits

Calls are limited per key. When the limit is hit the response is 429 with code rate_limited and a Retry-After header, in seconds. The default limit is 120 requests per minute.

Versioning and dates

checkDate (YYYY-MM-DD) selects the tax year. Rules are effective-dated. Send year-to-date wages in ytd so wage-base taxes stop at the right dollar.

Earning

{ code, category, amount }. amount is cents. category is regular or supplemental.

Deduction

{ code, category, amount }. Categories include deferral_401k and section125. Pretax and posttax are distinguished by category.

FederalW4

filingStatus (single, married_joint, married_separate, head_of_household), multipleJobs, dependentCredit, otherIncome, deductions, extraWithholding. Credit and dollar fields are cents.

YearToDate

socialSecurity, medicare, and futa wages in cents, for the employee so far this year. They cap Social Security, Additional Medicare, and FUTA.

StateWithholding

workState is { code, certificate }. Pennsylvania local tax uses workPSD and residencePSD. Ohio cities use workCity and residenceCity. A second state can be sent as residenceState.

PaycheckResult

grossPay, pretaxDeductions, posttaxDeductions, taxes[] with id, name, payer, jurisdiction, taxableWages, amount, detail, employeeTaxTotal, employerTaxTotal, netPay, plus notices and warnings when an input needs a second look.

POST /v1/address

Send a work address and, when you have it, a home address. The response includes a workState certificate you can reuse. A lookup that matches an address is counted like one calculation on a live key; a lookup that does not match is not billed.

GET /v1/states

Lists state codes the engine will calculate for the requested year.

GET /v1/me

Describes the key: mode, and how many calls it has made today.

GET /v1/health

Returns ok when the API process is up.

Pricing

14-day free trial, then $0.08 per paycheck calculation, pay as you go. A card is required at signup. Usage during the trial is recorded and is not charged. Each successful paycheck calculation is one charge. A calculation that does not succeed is not charged. Minimum wage and garnishment checks on the same paycheck are included. An address lookup is not a paycheck charge. There is no per-employee price and no minimum term.

Security

Security

How keys, modes, and limits work today. OMNIA TAX LLC operates the service.

API keys

Keys are stored as hashes. The full key is shown once, when it is issued. A key can be set to expire. After that the API returns expired_key.

Sandbox and live

Sandbox keys start with sk_test_. Live keys start with sk_live_. They are separate. Every response says which mode answered, in the Omnia-Mode response header.

Rate limits

Calls are rate limited per key. When you hit the limit the API returns 429 rate_limited and a Retry-After header.

Passwords and sessions

Passwords are hashed with scrypt and a fresh salt. They are never stored in a form that can be read back. The console session cookie is HTTP-only.

Card numbers

Card and bank account numbers are entered on the payment processor’s page. This server stores a processor reference and a last four, not the full number.

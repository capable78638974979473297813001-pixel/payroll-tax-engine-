Inside Omnia Engine

Every address resolved to the building it names.

Getting the state right is arithmetic. Getting the municipality right is geography — and a geocoder that interpolates puts the point on the street rather than the property. For 90 W Broad Street in Columbus that is 58 metres of drift, which near a municipal, JEDD or school district line is the difference between withholding and not. So Omnia resolves the building first.

  • Start from a surveyed point. Roughly 98 million address points published by the state, county and tribal governments that assign the addresses — the same records that route an ambulance to the right door.
  • Confirm it against the building. The point is tested against traced building footprints, so a surveyed coordinate and a structure seen from orbit have to agree before Omnia calls it rooftop.
  • Then test the boundary. Municipal, JEDD, school district and PSD lines are evaluated against a point that sits on the property itself, and the response tells you which method produced it.

For developers

An address goes in. A defensible paystub comes out.

Every amount is in integer cents and every tax line reports the taxable base it was computed on, so a number you shipped last quarter can be explained line by line this quarter.

  • Per-tax taxable bases. The same $240 of 401(k) deferral reduces federal wages, does not reduce Social Security wages, and does not reduce Pennsylvania wages.
  • Effective-dated by check date. A correction run in March for a December cheque uses December's rules, never today's.
  • Keys you control. Stored hashed, rotated on demand, rate-limited per key, with a sandbox that mirrors production data.

What the API does

Send the facts of a paycheck: earnings, deductions, the W-4, and where the employee works and lives. Every tax comes back calculated.

Gross to net in one call

Federal income tax by the Publication 15-T method, Social Security, Medicare, FUTA, state withholding and local taxes, in integer cents.

Taxable wages for each tax

Pre-tax deductions reduce each tax's wage base by that tax's own rules. A 401(k) deferral lowers federal income tax wages but not Social Security or Medicare wages.

Rules chosen by check date

Each calculation uses the rates in force on the check date, so a correction for a past period uses that period's rules.

Sourced rates, checked daily

Every rate records the official document it came from and when it was verified, and those sources are checked each morning. A missing rule returns an error, never a silent zero.

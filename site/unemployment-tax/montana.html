Unemployment tax by state

Montana unemployment tax: wage base and rate

What an employer pays in Montana, from the same rule files the API uses.

Montana's state unemployment tax (SUTA, also called SUI) is paid by the employer, on each employee's wages up to the state's wage base, which is $47,300 in 2026. Once an employee's wages for the year pass the base, no more state unemployment tax is due on them.

What the engine returns

Montana does not publish a single new-employer rate, so the engine returns no state unemployment line for a bare request. Send your assigned rate in employer.stateUnemploymentRate and it returns the line.

Use your own rate

The new-employer rate is a starting point. After your first period the state assigns a rate from your experience, and it is on your rate notice. Send it and the engine uses it instead:

"employer": { "stateUnemploymentRate": { "MT": 0.031 } }

Questions

What is the unemployment tax wage base in Montana?

$47,300 for 2026 in Omnia.tax's rule files. Montana's state unemployment tax applies only to each employee's wages up to that amount in a year.

What unemployment tax rate does a new employer pay in Montana?

Montana does not publish a single new-employer rate in Omnia.tax's rules, so the engine produces no state unemployment line unless you send your assigned rate in employer.stateUnemploymentRate.

How much is the maximum state unemployment tax per employee in Montana?

It depends on your assigned rate multiplied by the wage base of $47,300, because Montana does not publish a single new-employer rate.

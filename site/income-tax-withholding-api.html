Income tax withholding API

Which request fields drive income tax withholding, and what comes back.

The income tax part of POST /v1/paycheck is driven by four groups of fields. Everything else on the request (earnings, deductions, year-to-date wages) shapes the wages the tax is applied to.

The fields that matter

FieldWhat it controls
federalW4.filingStatusThe standard-deduction adjustment and which bracket table applies.
federalW4.multipleJobsStep 2 of the 2020-or-later Form W-4: uses the higher-withholding table.
federalW4.dependentCredit, otherIncome, deductionsSteps 3, 4(a) and 4(b), in cents.
federalW4.extraWithholdingExtra federal tax per paycheck, step 4(c).
workState.code and certificateWhich state formula runs and the state-specific withholding certificate answers.
residenceStateNeeded when the employee lives in a different state, for reciprocity and residence-based tax.

An example response

For a single employee in Texas paid $3,000.00 biweekly (Texas has no state income tax), the income tax line is:

TaxTaxable wagesAmount
Federal Income Tax$3,000.00$320.38

There is no state income tax line, because the engine returns a line only where a tax applies.

curl https://api.omnia.tax/v1/paycheck \
  -H "Authorization: Bearer $KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "checkDate": "2026-09-15",
  "payFrequency": "biweekly",
  "earnings": [{ "code": "REG", "category": "regular", "amount": 300000 }],
  "deductions": [],
  "federalW4": { "filingStatus": "single", "multipleJobs": false,
    "dependentCredit": 0, "otherIncome": 0, "deductions": 0, "extraWithholding": 0 },
  "ytd": { "socialSecurity": 0, "medicare": 0, "futa": 0 },
  "workState": { "code": "TX" }
}'

Exempt employees and overrides

The request accepts the W-4 exempt flag, extra withholding, and the voluntary-withholding agreement for categories that are otherwise exempt, so the response follows what the employee actually filed.

Questions

What does an income tax withholding API return?

For one paycheck, each federal, state and local income tax line with the wages it applied to, the amount in cents and a short explanation, plus the totals and net pay.

Does it support the current Form W-4?

Yes. It implements the 2020-or-later Form W-4: filing status, the multiple-jobs checkbox, the dependent credit, other income, deductions and extra withholding.

Are amounts in dollars or cents?

Integer cents everywhere, in requests and responses. A request that sends dollars with a decimal is rejected with a field-level error.

Payroll tax API test keys

The staging environment is the real engine with a cap, not a mock.

A test key (sk_test_) is for building your integration without a card or a bill. It returns the real calculation, because a mock that returns different numbers from production tests nothing.

What a test key is

Test keyLive key

Card neededNo (terms accepted)Yes
BilledNever$0.08 per paycheck, after a 14-day trial

ExpiresAfter 90 daysPer the key

Every response carries an Omnia-Mode: test or live header, and GET /v1/me tells you which kind of key you are holding.

What it is not

There is no separate pre-release server or data preview: a test key calls the production engine. It is capped so it cannot stand in for a live key.

The console

A signed-in visitor can also run the paycheck calculator without any key. It runs the same engine, is not billed, and shows the request as JSON and cURL to copy.

Questions

Is there a free tier or test environment for the payroll tax API?

Yes. A test key runs the same engine and data as a live key, needs no card and is never billed. It is capped at 30 requests a minute and 500 a day, and expires after 90 days.

Do test keys return real numbers?

Yes, the same numbers as a live key. There is no mock mode. The header Omnia-Mode tells you which kind of key made the call.

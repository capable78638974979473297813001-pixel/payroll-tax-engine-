Remote employee payroll tax in a different state

Two states, one paycheck, and rules about which one withholds.

When an employee works in one state and lives in another, the question is which state's income tax is withheld. The default is the state where the work is done. The employee's home state may tax the same wages too, usually with a credit on the return. Some pairs of states have reciprocity agreements that change the answer. Remote work makes this common.

A New Jersey resident working in Pennsylvania

The engine is given the work state (Pennsylvania, with a district) and the residence state (New Jersey). Pennsylvania and New Jersey have a reciprocal agreement, so the employer withholds for the state of residence and not for Pennsylvania. The state lines on a $3,000.00 check:

TaxTaxable wagesAmount
Pennsylvania Unemployment Compensation (Employee)$3,000.00$2.10
PA Local Earned Income Tax$3,000.00$102.75
New Jersey Income Tax (withheld by PA employer under reciprocity)$3,000.00$121.05

Total employee tax is $775.78 and net pay $2,224.22. Read the detail on each line to see which state's rule produced it.

Questions to settle for every remote employee

  • Where is the work physically done on each day? Some states tax by days worked in the state.
  • Is there a reciprocity agreement between the work and home states? See reciprocity.
  • Did the employee file the work state's nonresident certificate, or the home state's exemption form?
  • Does the employer have a registration obligation in the employee's home state?

Not legal advice

Questions

Which state do I withhold for a remote employee?

Usually the state where the work is done, unless a reciprocity agreement or the home state's rules say otherwise. The employee's home state may also tax the wages, with a credit on the return.

Do I have to register in the employee's home state?

That is a question of employer nexus and registration, which depends on the state. The engine does not decide it.

Engines and APIs

Payroll tax calculator API

The calculator page is for trying a paycheck. The API is for calculating them from your own software.

People search for a payroll tax calculator when they want to see what a paycheck costs. People search for a payroll tax calculator API when they want their software to do that for them. Omnia.tax is both, and they run the same engine and the same rules.

The calculator

The paycheck calculator takes an address or a state, pay, a Form W-4 and deductions, and shows each tax line with a one-line explanation. Signed-in visitors run it with no key. It also shows the exact request it sent, as JSON and as cURL, so you can copy it into your own code.

The API

The same request goes to POST /v1/paycheck with an API key. It returns JSON in integer cents, and it is documented in an OpenAPI 3.1 document and a JSON Schema.

Try it before you pay

A test key runs the same engine and data as a live key, needs no card, and is never billed. It is capped at 30 requests a minute and 500 a day. A live key is $0.08 per paycheck calculation after a 14-day free trial.

curl https://api.omnia.tax/v1/paycheck \
  -H "Authorization: Bearer $KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "checkDate": "2026-09-15",
  "payFrequency": "biweekly",
  "earnings": [{ "code": "REG", "category": "regular", "amount": 300000 }],
  "deductions": [],
  "federalW4": { "filingStatus": "single", "multipleJobs": false,
    "dependentCredit": 0, "otherIncome": 0, "deductions": 0, "extraWithholding": 0 },
  "ytd": { "socialSecurity": 0, "medicare": 0, "futa": 0 },
  "workState": { "code": "TX" }
}'
